# shape-area-polymorphism
A Python OOP project demonstrating inheritance, polymorphism, and method overriding by calculating the areas of circles, squares, and triangles.
<br>
Topics Covered:
<br>

1. Object-Oriented Programming (OOP)
2. Classes and Objects
3. Inheritance
4. Polymorphism
5. Method Overriding
6. Constructor (__init__)
7. superclass and subclass relationships
8. NotImplementedError
9. Python math Module
